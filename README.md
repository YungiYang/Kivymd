# Galaxy Defender — 2D Space Shooter на KivyMD

Космічний 2D скрол-шутер, розроблений мовою Python з використанням фреймворків **Kivy** та **KivyMD 2.0**, оптимізований для мобільних пристроїв під управлінням **Android** та настільних систем.

---

## Особливості та реалізовані механіки

### 1. Структура додатку
- Реалізовано 3 повноцінних екрани через `MDScreenManager`:
  - **Головне меню (`menu_screen`)**: Назва гри, інструкція керування, запуск гри та вихід.
  - **Ігровий екран (`game_screen`)**: Поле бою, графічний HUD (смужка HP, активний щит, комбо, рахунок), пауза та керування.
  - **Game Over (`game_over_screen`)**: Фінальний результат, найкращий рекорд, кнопки перезапуску та повернення в меню.

### 2. Прогресивна система карток покращень (Escalating Upgrades)
- Вартість кожного наступного покращення **прогресивно зростає**: після кожної обраної картки для наступної потрібно все більше й більше очок!
  - **1-ше покращення:** при **1 000 очок** (потрібно +1 000)
  - **2-ге покращення:** при **2 500 очок** (потрібно +1 500)
  - **3-тє покращення:** при **4 500 очок** (потрібно +2 000)
  - **4-те покращення:** при **7 000 очок** (потрібно +2 500)
  - **5-те покращення:** при **10 000 очок** (потрібно +3 000)
- Гра автоматично ставиться на паузу та відкриває модальне вікно вибору **1 з 3 випадкових карток покращень**:
  - 💥 **Подвійний / Потрійний лазер:** Стрільба 2 або 3 лазерами паралельно по фронту.
  - ⚡ **Швидкострільність:** +30% до темпу стрільби.
  - ☄️ **Потужні заряди:** +18 до шкоди кожної кулі.
  - 🛡️ **Енергетичний щит:** +2 заряди захисного силового поля, що повністю поглинають влучання ворогів та відображаються неоновим куполом навколо корабля.
  - ❤️ **Нано-броня & Ремонт:** +25 до макс. HP та повне відновлення здоров'я.
  - 🚀 **Турбодвигуни:** +25% до швидкості та маневреності корабля.
  - 🎯 **Гіперзвуковий лазер:** +35% швидкості куль та +8 до шкоди.
- Вибір картки здійснюється натисканням на неї (сенсор/мишка) або швидкими клавішами `1`, `2`, `3` на ПК.

### 3. Різноманітні типи ворожих кораблів (5 Enemy Classes & Attacks)
- 🔴 **Винищувач (Fighter):** Базовий бойовий корабель зі збалансованою швидкістю та прямим лазерним вогнем вниз.
- 🟡 **Швидкий розвідник (Scout):** Маневрений легкий корабель, що летить по зигзагоподібній синусоїді та веде частий вогонь швидкими жовтими зарядами.
- 🎯 **Снайпер (Sniper):** Далекобійний корабель, що відстежує вектор розташування гравця та спрямовує прицільні швидкісні червоні лазерні промені точно у ціль.
- 💣 **Важкий бомбардувальник (Bomber):** Броньований корабель із 55 HP, який здійснює небезпечний 3-променевий віяловий залп (`\ | /`).
- 🟣 **Важкий крейсер (Cruiser):** Велетенський корабель із 90 HP, власною смужкою здоров'я над корпусом та спареними важкими плазмовими гарматами з обох бортів.
- Частота та пропорції спавну різних класів адаптуються та ускладнюються в міру набору очок.

### 4. Гігантські флагмани-боси з ескалацією складності (Escalating Boss Battles)
- **Поява боса:** При досягненні рубіжних очок (перший бос при ~2000 очок, наступні — через зростаючі інтервали) лунає сирена та блимає банер тривоги `⚠️ УВАГА! НАБЛИЖАЄТЬСЯ ФЛАГМАН БОС! ⚠️`.
- **Ескалація характеристик:** Кожен наступний бос (`Рівень 1, 2, 3...`) значно сильніший:
  - Збільшений запас здоров'я (`300 HP -> 500 HP -> 700 HP...`);
  - Вища швидкість горизонтального маневрування;
  - Прискорений темп стрільби (зменшений кулдаун гармат);
  - Більша нагорода очками (`+1800 -> +2400 -> +3000...`).
- **3 динамічні фази атак боса:**
  1. *5-променевий віяловий шквал* по всьому полю бою;
  2. *Подвійний прицільний лазерний залп* безпосередньо у координати гравця;
  3. *Плазмовий струмінь з 3 бортових батарей*.
- **Окремий інтерфейс боса:** Верхня смужка здоров'я з ім'ям флагмана, рангом та динамічним індикатором залишку HP.
- **Епічний фінал:** При знищенні бос вибухає масштабним 3-колірним феєрверком часточок і приносить величезний бонус очок.

### 5. Комбо-множник та спливаючий бойовий текст (Floating Combat Text)
- Знищення ворогів підряд формує **комбо-множник** (`x1.25`, `x1.5`, `x2.0`), що примножує зароблені бали.
- Динамічний спливаючий текст для:
  - Нарахованих очок (`+100`, `+350`, `COMBO x2!`);
  - Отриманої шкоди (`-15 HP`, `-25 HP`);
  - Блокування ударів щитом (`ЩИТ! 🛡️`);
  - Отриманих покращень (`⭐ Подвійний лазер!`).

### 6. Гравець (PlayerShip)
- Сенсорне керування (Android): перетягування пальцем або кнопки `<` та `>` внизу.
- Клавіатурне керування (ПК): стрілки `Left`/`Right` або `A`/`D`, пробіл — стрільба, `P` — пауза.
- Анімація сопел двигуна системою часточок (Particle System).
- Візуальний енергетичний щит навколо корпусу при наявності захисних зарядів.

### 7. Рухомий паралакс-фон (Parallax Background)
- 2 незалежні шари зоряного простору з різною швидкістю та глибиною.
- Безшовне перенесення зірок при виході за межі екрана.

## Запуск гри

```bash
# Запуск з кореня проекту:
python main.py
```

### Запуск автоматичних тестів:

```bash
# Перевірка базових компонентів:
python tests/test_game.py

# Перевірка системи карток покращень (кожні 1000 очок):
python tests/test_upgrades.py

# Перевірка сенсорного та кнопкового керування:
python tests/test_controls.py

# Перевірка паузи:
python tests/test_pause_click.py
```
