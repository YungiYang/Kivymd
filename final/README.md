# Galaxy Defender — 2D Space Shooter на KivyMD

Космічний 2D скрол-шутер, розроблений мовою Python з використанням фреймворків **Kivy** та **KivyMD 2.0**, оптимізований для мобільних пристроїв під управлінням **Android** та настільних систем.

---

## Особливості та реалізовані вимоги

### 1. Структура
- Реалізовано 3 повноцінних екрани через `MDScreenManager`:
  - **Головне меню (`menu_screen`)**: Назва гри, інструкція керування, запуск гри та вихід.
  - **Ігровий екран (`game_screen`)**: Поле бою, динамічний HUD (HP бар, рахунок), пауза та керування.
  - **Game Over (`game_over_screen`)**: Фінальний результат, найкращий рекорд, кнопки перезапуску та повернення в меню.

### 2. Гравець (PlayerShip)
- Рух ліворуч і праворуч:
  - **Сенсорне керування (Android):** перетягування корабля пальцем у будь-якій точці екрана або зручні нижні кнопки `<` та `>`.
  - **Клавіатурне керування (ПК):** стрілки `Left`/`Right` або клавіші `A`/`D`.
- Стрільба лазерами з обмеженням скорострільності (кулдаун).
- Система HP (здоров'я) з візуальним відображенням на панелі HUD.
- Анімація корабля системою часточок (Particle System) — з сопла двигуна вилітають часточки полум'я та плазми.
- Завершення гри при `HP <= 0`.

### 3. Вороги (Enemy)
- Автоматична поява (спавн) за таймером у випадкових координатах зверху.
- Рух вниз із різною індивідуальною швидкістю.
- Ворожі винищувачі ведуть прицільний вогонь по гравцю вниз.
- Мають запас HP та смужку здоров'я; знищуються з ефектом вибуху часточок і приносять бали.

### 4. Кулі (Bullet)
- Окремий клас `Bullet` для куль гравця та ворогів.
- Рух у правильному напрямку: вгору для гравця, вниз для ворогів.
- AABB колізії:
  - Куля гравця $\rightarrow$ Ворог (завдає шкоди, знищує, нараховує бали).
  - Куля ворога $\rightarrow$ Гравець (знімає HP, генерує спалах пошкодження).
- Видалення куль при зіткненні або вильоті за межі екрана.

### 5. Ігровий цикл (Game Loop)
- Фіксований 60 FPS цикл (`Clock.schedule_interval`).
- Оновлення гравця, ворогів, куль, анімації часточок та фону в кожному кадрі.

### 6. Рухомий паралакс-фон (Parallax Background)
- 2 незалежні шари зоряного простору з різною швидкістю та глибиною.
- Безшовне перенесення зірок при виході за екран.

### 7. Пауза
- Кнопка паузи у верхньому правому кутку (або клавіша `P`/кнопка «Назад» на Android).
- Зупиняє ігровий цикл `Clock` та блокує рух/спавн.
- Оверлей з кнопками «Продовжити» та «Головне меню».

## Запуск на комп'ютері

```bash
# Запуск гри:
py -3.13 main.py
# або
python main.py
```

### Запуск автоматичних тестів:
```bash
py -3.13 tests/test_game.py
```

## Збірка під Android (APK)

Для збірки інсталяційного пакета APK використовується інструмент `buildozer` (через Linux або WSL):

```bash
buildozer android debug
```
Згенерований APK-файл буде знаходитися у папці `bin/`.
